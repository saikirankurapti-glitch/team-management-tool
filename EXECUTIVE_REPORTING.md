# Executive Dashboard & Report Scheduling

## 1. Executive Dashboard Overview (`/analytics/executive`)
High-level executive dashboard summarizing:
- **Company / Organization Portfolio**: Active projects, healthy/at-risk/critical breakdown.
- **Top Active Risks**: Top 5 active risk observations with human-readable explanations.
- **Delivery Trends**: Overall completion %, throughput, and average cycle times.

## 2. Scheduled Report Automation
Reports can be scheduled for recurring delivery (`DAILY`, `WEEKLY`, `MONTHLY`) stored in the `ReportSchedule` table with recipient email lists and execution logs.
