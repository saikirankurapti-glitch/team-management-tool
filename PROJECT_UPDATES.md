# Project Updates & AI Status Generator (`ProjectUpdate`)

## 1. Project Health Statuses
Tracks `ON_TRACK`, `AT_RISK`, and `CRITICAL` project health with structured summaries, completed items, next steps, and open risks.

## 2. AI Update Generator (`POST /api/v1/updates/ai-draft`)
Uses real database metrics (completed work items, active items, sprint progress) to draft project status updates for manager review.
