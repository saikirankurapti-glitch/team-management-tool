# Commercial SaaS Customer Lifecycle Specifications

## 1. Customer Journey Flow
```text
  Landing Page ➔ Public Signup ➔ Onboarding Wizard ➔ 14-Day Free Trial ➔ Project Setup ➔ Team Usage ➔ Metering ➔ Upgrade Plan ➔ Retention
```

## 2. Customer Activation Milestones
- **Milestone 1**: Organization workspace created & 14-day trial initialized.
- **Milestone 2**: First project created from template (*Software Development* or *General Operations*).
- **Milestone 3**: Team member invited via email.
- **Milestone 4**: First work item created or imported.
- **Milestone 5**: GitHub development integration connected.
