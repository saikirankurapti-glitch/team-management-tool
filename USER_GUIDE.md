# End-User Guide: Mobile & PWA Usage

## 1. Installing as a PWA
On mobile devices (iOS Safari or Chrome Android), tap **Add to Home Screen** to install StartupHub as a standalone Progressive Web App with app shortcuts for My Work, Chat, and Knowledge.

## 2. Touch Navigation & Offline Sync
- Use the bottom navigation bar for quick access to Home, My Work, Projects, Chat, and Alerts.
- Use the slide-out menu drawer for Knowledge Hub, Templates, Calendar, and Settings.
- When offline, status edits and comments are saved locally and synced automatically upon network recovery.
