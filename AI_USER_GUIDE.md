# AI Copilot User Guide

## 1. Opening the Copilot Side-Panel
Click the **✨ AI Copilot** button in the top navigation bar from any page in the platform.

## 2. Quick Prompts
- **Project Risks**: *"Which projects are at risk and why?"*
- **Team Capacity**: *"Who is overloaded this sprint?"*
- **Draft Work Item**: *"Create bug for checkout API timeout"*
- **Move Status**: *"Move PROJ-101 to Testing"*

## 3. Confirming Proposals
When requesting task creation or column moves, Copilot displays a **Proposal Card**. Click **Confirm** to execute the change.
