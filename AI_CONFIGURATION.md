# AI Copilot Configuration & Cost Control Standards

## 1. Governance Configuration (`Settings -> AI`)
- **Enable/Disable Copilot**: Global toggle for AI features.
- **Monthly Usage Limits**: Configurable monthly token limits (default `10,000` tokens) with usage progress indicators to prevent runaway costs.
- **Provider Selection**: Switch between `MOCK_OPENAI` and production `OPENAI` API endpoints.
