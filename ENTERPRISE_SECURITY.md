# Enterprise Security Architecture & Security Center

## 1. Security Overview (`/settings/security`)
The Enterprise Security Center allows organization administrators to manage:
- **Single Sign-On (SSO)**: SAML 2.0 and OIDC provider integration status.
- **API Credentials**: Active API keys and scope allocations.
- **Outbound Webhooks**: HMAC-SHA256 signed customer webhook endpoints.
- **Audit Logs**: Immutable audit log of security events.
