# Automation Rule Templates Specifications

## Pre-Built Automation Rules
1. **Overdue Task Alert**: WHEN task becomes overdue THEN notify assignee and project manager.
2. **High Priority Bug Escalation**: WHEN high severity bug is created THEN ping team channel.
3. **PR Merged Status Transition**: WHEN GitHub PR is merged THEN move work item to `CODE_REVIEW` or `TESTING`.
4. **Sprint Expiration Warning**: WHEN sprint has 1 day remaining THEN notify team.
