# Project & Organization Template Specifications

## 1. Built-in Templates
- **Agile Software Development**: Epics, Stories, Tasks, Bugs, Kanban WIP limits, and Sprint cycles.
- **Scrum Framework**: Backlog management, sprint planning, reviews, and retrospectives.
- **Kanban Workflow**: Continuous flow board with To Do, In Progress, Review, and Done states.
- **Product Launch**: Discovery ➔ Planning ➔ QA ➔ Launch.

## 2. Template Variables & Customization (`ProjectTemplate`)
Supports template variable resolution (`{{PROJECT_NAME}}`, `{{TEAM_NAME}}`, `{{START_DATE}}`) when instantiating new projects.
