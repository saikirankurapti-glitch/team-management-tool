# Future Integrations & Feature Roadmap

## Planned Extensibility Boundaries
- **GitHub / GitLab Integration**: Automated status transitions based on PR commits (e.g. `Fixes PROJ-102`).
- **Slack / Teams Integration**: Webhook notification dispatch to external company channels.
- **Google Calendar / Outlook Sync**: Export delivery deadlines and sprint milestone windows directly to personal calendar apps.
- **CI/CD Build Pipeline Tracking**: Display build test execution status on Kanban card badges.
